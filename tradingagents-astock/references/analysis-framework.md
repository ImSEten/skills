# A 股多智能体投研分析方法

本文件定义 Hermes 对 A 股标的做多智能体投研分析的方法：先由 `scripts/fetch_data.py`
获取真实数据，再按七个维度独立研判，经多空辩论与风险管控后给出评级。

## 分析流程总览

1. **数据采集**：`terminal(command="python <技能目录>/scripts/fetch_data.py <代码或中文名> --date <YYYY-MM-DD>")`，得到分节 Markdown 数据素材。
2. **七维度独立研判**：对每个维度基于数据给出独立结论（见下），标注数据是否缺失/告警。
3. **多空辩论**：围绕核心分歧点，分别以多头、空头立场论证并互相反驳。
4. **风险管控**：以激进/保守/中立三方视角审视，形成风险清单。
5. **综合决策**：给出评级（Buy/Hold/Sell）、方向与理由。

## 维度一：技术面（市场分析师）

数据块：`kline`（OHLCV CSV，必要时自行计算均线/动量或基于高低点判断）。

- **趋势**：用收盘价序列判断阶段高低点与均线方向（多头/空头排列、突破/跌破）；短线强弱。
- **动量与超买超卖**：可自行计算 MACD/RSI 或依据近期涨跌幅、放量/缩量特征定性判断。
- **波动与通道**：区间高低点、振幅；ATR 可从日高低收估算波动率。
- **量价关系**：放量突破 vs 缩量回调 vs 放量滞涨（出货嫌疑）。
- **A 股语境**：涨停/跌停会截断当日价格与成交，一字板无法买入/卖出；T+1 下当日买入不能当日止盈。

完成判据：对趋势、动量、波动、量价各给出一句结论，并指出关键支撑/压力位（基于 K 线高低点，不输出可执行价位）。

## 维度二：情绪面（舆情分析师）

数据块：`news`、`hot_stocks`。

- 个股与行业新闻讨论热度、标题情绪（乐观/悲观/中性）、近期新闻密集度。
- 舆论一致看多时警惕拥挤；无人问津时注意流动性风险。
- 结合 `concept` 判断标的是否处于市场热门题材。
- `hot_stocks` 给出当日涨停/强势股及其题材归因与题材热度排行，判断标的所在题材
  是否处于市场风口（注意：涨停事件库只保留近期交易日）。

## 维度三：新闻面（新闻分析师）

数据块：`news`、`global_news`。

- 公司公告：业绩预告、增减持、重大合同、诉讼、监管函。
- 行业新闻与宏观事件：货币/财政/产业政策、外围市场。
- 按利好/利空分类，标注时间窗口与影响级别；注意新闻可能滞后于价格。

## 维度四：基本面（基本面分析师）

数据块：`quote`、`reports`（三表合一，含已公布截断）、`forecast`、`shareholders`。

- **盈利能力**：营收/净利同比增速、毛利率/净利率趋势（利润表 + 资产负债表）。
- **财务健康**：资产负债率、流动/速动资产、有息负债规模（资产负债表）。
- **现金流质量**：经营现金流与净利润是否匹配、投资/筹资现金流方向（现金流量表）。
- **估值**：PE(TTM)/静态 PE、PB、总市值（亿元）（`quote` 实时值；历史分析时标注为快照）。
- **成长预期**：`forecast` 一致预期的每股收益/净利润均值与区间、预测机构数
  （机构数 <3 时覆盖不足，谨慎引用；一致预期无历史时点值，历史分析时标注为快照）。
- **股东结构**：`shareholders` 十大股东/流通股东持股比例与变动（增减持/新进）、
  股东户数变化与筹码集中度（户数降 = 筹码集中，升 = 分散）。
- **A 股特有风险点**：审计意见类型、商誉占比与减值风险、大额关联交易、股权质押比例（结合新闻判断）。

完成判据：给出盈利、财务、估值三方面结论，并明确指出基本面主要矛盾（如"成长快但估值贵"）。

## 维度五：政策面（政策分析师）

数据块：`global_news`、`news`、`industry`、`concept`。

- 产业政策（补贴、准入、监管、数据要素/算力/新能源等主题）、货币政策（利率/流动性）。
- `industry` 板块强弱排名中标的相关板块位置；`concept` 概念归属。
- A 股是政策市：政策信号直接影响板块轮动与估值中枢，需判断政策方向与标的受益/受损关系。

## 维度六：资金面（游资追踪师）

数据块：`fundflow`、`northbound`、`lhb`、`concept`。

- 主力/超大单资金净流入的持续性与方向（实时分钟 + 近 20 交易日历史日线）。
- 北向资金（沪深股通）当日方向；仅实时快照，无历史日度序列。
- 龙虎榜：上榜原因、买卖前五席位（游资 vs 机构）、净买额、机构参与度。
- 板块效应：标的是否处于当前资金主线题材内（`concept` 当日涨跌）。

完成判据：回答"资金在流入还是流出、短线资金还是中长线资金、有无游资/机构席位信号"。

## 维度七：解禁面（解禁监控师）

数据块：`lockup`、`news`。

- 未来 90 日解禁规模与占总股本比例、解禁类型（首发原股东/定增/股权激励）。
- 解禁 ≠ 立即减持，但构成供给冲击预期；结合大股东减持公告与股权质押水平判断实际减持压力。
- 已发生的解禁后股价表现可作为参考。

## 多空辩论

对每个核心分歧点（例如"估值高 vs 成长确定"、"资金流入 vs 解禁压力"）：

1. **多头论据**：列出支撑看多的数据（每一条注明数据来源块）。
2. **空头论据**：列出支撑看空的数据。
3. **互相反驳**：双方针对对方最有力的论据给出反证。
4. **阶段性裁决**：每轮后说明当前天平倾向与关键变量。

规则：论据必须来自已获取的数据，不得凭空假设；数据缺失时明说"该维度数据不可得"。

## 风险管控（三方视角）

- **激进视角**：上行弹性、主升逻辑是否成立。
- **保守视角**：最大下行风险、流动性、黑天鹅（退市/ST/财务造假/政策突变）。
- **中立视角**：概率权衡，什么条件下逻辑被证伪。
- **输出风险清单**：风险点、级别（high/medium/low）、描述，逐条对应数据或事实。

## 最终决策与输出格式

- **评级**：`Buy` / `Hold` / `Sell`（独立词，避免 `Buyer interest`、`Sell-off` 这类延续词被误读）。
- **方向**：看多 / 看空 / 中性，与评级一致。
- **理由**：2–5 条核心依据，每条可追溯到数据块。
- **风险**：引用风险清单的高/中级别项。
- 只输出方向、评级与理由；**不产出建仓价/止损位/仓位/目标价**。
- 报告末尾附免责声明：内容由 AI 基于公开数据自动生成，仅供研究参考，不构成投资建议。
