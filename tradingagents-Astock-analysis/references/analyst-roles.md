# 21 名分析师角色与数据映射

本文件定义 Hermes 在 `tradingagents-Astock-analysis` 中扮演的 **21 名 AI 分析师**：各自的职责、
输入数据块（来自 `scripts/fetch_data.py` 的免费直连数据）与分析要点。
六个阶段依次执行：**分析团队 → 博弈裁判 → 多空辩论 → 交易执行 → 风险管控 → 综合决策**。

数据块速查：`overview`（名称+实时行情）、`quote`（实时行情/估值）、`kline`（日K线）、
`reports`（财报三表）、`forecast`（机构一致预期）、`news`（个股新闻）、`global_news`（财经快讯）、
`hot_stocks`（热门强势股题材）、`lhb`（龙虎榜）、`lockup`（限售解禁）、`shareholders`（股东动态）、
`industry`（行业对比）、`fundflow`（资金流）、`concept`（概念板块）、`northbound`（北向资金）。

## 阶段一：分析团队（10 名分析师）

维度权重沿用七维框架（经营状态30% · 政治局势25% · 估值20% · 资金10% · 技术10%辅助 · 情绪5%辅助 ·
解禁并入资金）。⑦⑨并入经营维度、⑧并入资金维度、⑩并入情绪维度——不另占权重，作为主维度的补充视角。

### ① 经营与基本面分析师（权重 30% · 核心维度）

- 数据：`quote`、`reports`、`forecast`、`shareholders`
- 要点：经营竞争力（行业地位、市场份额、技术壁垒、客户粘性）、盈利能力趋势（营收/净利同比、毛利率/净利率，
  判断是否"增收不增利"）、财务健康（资产负债率、流动/速动资产、有息负债）、现金流质量（经营现金流与净利润匹配度）、
  成长预期（`forecast` 一致预期，机构数 <3 时谨慎引用）、A 股特有风险点（审计意见、商誉、关联交易、质押）。
- **长期视角**：核心判断"公司当前经营质量能否支撑 2-3 年持有"。
- 输出：经营竞争力 + 盈利趋势 + 财务健康 + 现金流质量 + 主要矛盾。

### ② 政策与公司前景分析师（权重 25% · 核心维度）

- 数据：`global_news`、`news`、`industry`、`concept`
- 要点：产业政策方向（补贴/准入/监管/数据要素/算力）、监管环境、技术路线前景（5G-A/6G/AI/算力演进）、
  竞争格局（行业集中度、主要对手）、海外政策环境（地缘、贸易壁垒、出海）、行业景气度（`industry` 板块排名）。
- **长期视角**：核心判断"产业方向是否确定、政策是否友好、技术路线是否可持续"。
- 输出：政策环境 + 技术路线 + 竞争格局 + 长期前景判断。

### ③ 估值分析师（权重 20%）

- 数据：`quote`、`reports`、`forecast`、`shareholders`
- 要点：盈利预测验证（2026-2028E 一致预期 EPS/净利、机构数、行业平均对比）、前瞻估值水平（PE/PB/PEG 与分位）、
  估值安全边际（前瞻 PE 与历史区间/同业对比）、成长预期斜率（EPS 增速 CAGR 能否消化估值）、ROE 趋势。
- 输出：前瞻估值是否合理 + 成长能否消化估值 + 长期估值安全边际判断。

### ④ 资金与聪明钱分析师（权重 10%）

- 数据：`fundflow`、`northbound`、`lhb`、`concept`
- 要点：主力/超大单净流入方向与持续性（实时分钟 + 近 20 交易日历史日线）、北向当日方向（仅实时快照）、
  龙虎榜席位（游资 vs 机构）与净买额、标的是否处于资金主线题材。
- **长期视角**：关注机构持仓变化趋势而非短期游资进出，忽略龙虎榜短线席位。
- 输出：聪明钱方向（机构持仓趋势为主，资金流为辅）。

### ⑤ 技术面与市场分析师（权重 10% · 辅助参考）

- 数据：`kline`
- 要点：趋势（阶段高低点/均线方向）、动量与超买超卖（MACD/RSI 或涨跌幅/量价特征）、波动与通道（区间/振幅/ATR）、
  量价关系（放量突破 vs 缩量回调 vs 放量滞涨）、A 股语境（涨跌停/T+1 扭曲当日量价）。
- **重要**：本维度仅辅助参考，不作为长期投资评级依据。
- 输出：趋势方向 + 动量 + 波动 + 量价各一句 + 关键支撑/压力位（不输出可执行价位）。

### ⑥ 情绪与舆情分析师（权重 5% · 辅助参考）

- 数据：`news`、`hot_stocks`、`concept`
- 要点：个股与行业新闻热度与标题情绪（乐观/悲观/中性）、舆论一致看多时警惕拥挤、无人问津时注意流动性风险、
  结合 `concept` 判断是否处于热门题材、`hot_stocks` 判断题材是否处于市场风口。
- **长期视角**：关注中期舆情，忽略短期涨停潮。
- 输出：情绪温度（冷/温/热）+ 一致性判断。

### ⑦ 新闻事件分析师（并入经营维度，不另占权重）

- 数据：`news`
- 要点：公司公告（业绩预告、增减持、合同、诉讼、监管函）、行业事件；按利好/利空分类并标注时间窗口；
  逾期披露本身是风险信号。
- 输出：新闻面结论 + 关键事件列表。

### ⑧ 解禁与供给冲击分析师（并入资金维度，不另占权重）

- 数据：`lockup`、`news`
- 要点：历史解禁记录 + 未来 90 天待解禁规模与占总股本比例、结合减持公告与股权质押判断实际减持意愿。
- **长期视角**：低频关注；解禁 ≠ 立即减持，但构成供给冲击预期。
- 输出：解禁压力判断（高/中/低）+ 关键解禁节点。

### ⑨ 股东与筹码分析师（并入经营维度，不另占权重）

- 数据：`shareholders`
- 要点：十大股东/十大流通股东持股比例与变动（增减持/新进）、股东户数变化与筹码集中度
  （户数降 = 筹码集中，升 = 分散）、机构持仓趋势。
- 输出：股东结构变化 + 筹码集中度判断。

### ⑩ 板块与题材分析师（并入情绪维度，不另占权重）

- 数据：`industry`、`concept`、`hot_stocks`
- 要点：行业涨跌排名中标的相关板块位置、概念归属与当日涨跌、涨停强势股题材归因与题材热度 TOP15，
  判断标的所在题材是否处于市场主线。
- 输出：板块强弱 + 题材归属 + 风口判断。

## 阶段二：博弈论管理者（1 名）

### ⑪ 博弈论管理者

- 数据：`kline`、`fundflow`、`lhb`、`northbound`、`concept`
- 要点：判断**主力与散户的预期差**——谁在买、谁在卖；散户情绪是否一致（一致看多时警惕出货）；
  龙虎榜席位意图（接力/出货）；价格行为与资金流是否背离。
- 输出：预期差判断 + 对后续走势的含义。

## 阶段三：多空辩论（3 名）

### ⑫ 多头研究员

- 数据：全部
- 要点：列出支撑看多的最强论据（逐条注明数据块），并反驳空头最有力的观点。
- 输出：多头论据清单。

### ⑬ 空头研究员

- 数据：全部
- 要点：列出支撑看空的最强论据（逐条注明数据块），并反驳多头最有力的观点。
- 输出：空头论据清单。

### ⑭ 裁判

- 数据：两方辩论记录
- 要点：逐条评判论据质量（数据支撑 vs 主观推测），裁决当前天平倾向与关键变量；每轮辩论后给出阶段性裁决。
- 输出：综合投资计划（方向 + 依据）。

## 阶段四：交易执行（1 名）

### ⑮ 交易员

- 数据：`kline`、`quote`；规则参考 `references/a-share-rules.md`
- 要点：在 A 股约束（T+1、涨跌停、最小 100 股、科创板 200 股）下将研究转化为方案：
  方向、参考价位区间（基于支撑/压力与 ATR）、持有期设想。
- 输出：交易方案文本；`target_price`/`stop_loss_price` 估算值（**仅研究参考**，标注不确定性）。

## 阶段五：风险管控（4 名）

### ⑯ 激进分析师

- 数据：全部 + `lockup`
- 要点：上行弹性、主升逻辑是否成立。
- 输出：上行风险/机会观点。

### ⑰ 中性分析师

- 数据：全部
- 要点：概率权衡，什么条件下逻辑被证伪。
- 输出：证伪条件清单。

### ⑱ 保守分析师

- 数据：全部 + `lockup`
- 要点：最大下行风险（解禁/减持/ST/退市/流动性/黑天鹅）。
- 输出：最大下行风险观点。

### ⑲ 组合经理

- 数据：以上全部
- 要点：汇总三方风控，形成风险清单（风险点/级别 high-medium-low/描述，逐条对应数据或事实），
  给出最终评级与理由。
- 输出：`final_trade_decision`。

## 阶段六：综合决策（2 名）

### ⑳ 独立复核官

- 数据：阶段一至五的全部结论与风险清单
- 要点：对照七维权重表复核各阶段结论与权重的一致性；横向比对 10 名分析师的结论，
  列出**一致点**（多专家共同支持 = 双源确认）与**分歧点**（暴露盲区，不掩盖）；
  对缺失/告警数据块的影响做降级标注。给出置信度（0-100）：一致点越多越高、分歧越多越低。
- 输出：`consistency`（一致点清单）、`divergence`（分歧点清单）、`confidence`（0-100）。

### ㉑ 首席决策官

- 数据：独立复核官输出 + 组合经理结论
- 要点：最终裁定——综合评级 `Buy`/`Hold`/`Sell`（独立词，避免 `Buyer interest`、`Sell-off` 延续词）、
  方向（看多/看空/中性，与评级一致）、3-5 条可追溯理由（每条注明支撑它的专家与数据块）、
  引用风险清单的高/中级别项。
- 输出：最终决策文本 + 结构化 JSON（见 SKILL.md「输出结构」）。

## 输出聚合

首席决策官产出后，将全部分析聚合为结构化 JSON（见 SKILL.md「输出结构」）：
`decision` / `direction` / `confidence` / `target_price` / `stop_loss_price` /
`risk_items` / `key_metrics` / `final_trade_decision`，并附 `consistency` / `divergence` 复核字段。

- `target_price`/`stop_loss_price` 由交易员基于支撑/压力与 ATR 估算，**仅研究参考**，标注不确定性。
- 评级口径：`BUY`/`SELL`/`HOLD`，与方向一致；`confidence` 由独立复核官综合多源一致度给出 0-100。
